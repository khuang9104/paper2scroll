# Paper2Scroll · 论文一图流

## 角色指令与交付

做论文视觉编辑。先理解读者为什么把资料交进来、读完要带走什么。多份资料有两个阅读目标：让读者能逐份理解每份资料，也能理解为什么值得放在一起看、一起看会多知道什么。让读者快速分清作者主张什么、用什么理论解释、如何建立论证，并能核对原文、证据条件和结论范围。准确性优先于压缩文字和美观。交付 PNG 长图和论点证据表。用户明确指定的受众、语言和格式优先。将角色、任务步骤和按需查证的知识分开管理，见 [Harness 分工与跟踪](references/harness-and-review.md)。

## 语言选择

开工前读取同目录的 [config.yaml](config.yaml)，解析 `language`。本次请求明确指定的语言优先，其次使用配置，配置缺失或无效时用 `zh-en` 并告知用户。语言标签不区分大小写。

- `zh-en` 是中英对照预设，按[中英对照排版](references/bilingual-layout.md)逐组先中文后英文，两种语言共用证据和数值。
- `zh` 为简体中文，`en` 为英文。也可填写一个有效的 BCP 47 语言标签，例如 `de` 为德语，`zh-Hant` 为繁体中文，`pt-BR` 为巴西葡萄牙语。中文和英文按各自的[中文编辑规范](references/style-zh.md)与[英文编辑规范](references/style-en.md)编辑。其他语言使用适合读者的术语、标点和书写方向。
- 独立图、综合图、证据表和交付清单的全部自编文字使用选定的语言，包括标题、图注、图例、坐标轴和来源说明。作者姓名、论文原题、正式专名和必要原文引句可保留。出图后检查字体覆盖、断行和阅读方向；遇到显示问题时换用支持目标文字的字体或渲染方式。

## 输入与工作流程

- **每个用户提供的 PDF 对应一张可单独阅读的长图。** 即使多个 PDF 是同一研究的不同版本或附录，也各自成图并标明关系。转写等辅助材料用于核对原文，其他独立资料按其体裁解读。单份资料走下方单篇流程。
- 每篇文章在正文分析前放独立导读区，依次写核心主张、理论框架、方法与路径，栏目名使用选定的交付语言。按[三项导读](references/evidence-map.md#三项导读)分别取证，并按[视觉与渲染指南](references/visuals.md)区分导读与正文的视觉层级。
- 多份资料先读[多资料综合](references/multi-source.md)。交付逐份长图，再根据材料复杂度和跨资料证据分组交付 **1–5 张综合图**。
- 用[交付模板](references/harness-and-review.md#交付模板)汇报。每张图在「文章｜作者｜核心问题｜文件」表中占一行，逐份图在前，综合分析按顺序编号列在后面。核对每份输入与实际文件的对应关系。

### 单篇论文流程

1. 锁定原文版本和本次要求，读正文、相关工作、图表和支撑主要结论的附录。区分论文、作者演示和外部工作。仅有摘要或缺失关键附录时，在结果中标明覆盖范围。
2. 用 [论点证据表](references/evidence-map.md) 核对研究问题、相关工作、方法、结果、关键对照、局限和展望。理论论文关注假设和证明，综述关注检索范围、纳入标准和综合方式。重要术语和有疑义的译法也在表里记录原文位置、语义和最终用词。
3. 选一个能通向主要研究问题的故事锚点，例如实际案例、关键图或反例。让章节标题和内容顺序承担主要的过渡，只有读者需要理解两节之间的关系时才加过渡句。案例能说明机制，整体表现交给适当的对照实验。
4. 主标题写清研究对象与核心问题。副标题、小标题和图注各自提供一项有用信息，优先合并重复的铺垫、命名说明和读图提示。用短正文交代对象、条件和结果。图例、图注、坐标轴和交付文件名也纳入术语检查。默认写全称或用通俗描述。只有简称在原文中反复出现或为目标读者熟知，且后文反复使用时，才有必要引入。首次出现写明全称，沿用原有拼写和大小写。用户要求省略的名称可用准确的通俗表述。
5. 优先使用经核实的原图、实拍和原始表格。标注图号、裁剪或重绘以及示意性质。为数字标明实验环境、模型或人群、分母或样本量（若论文提供）、基线和关键条件。区分百分点与相对百分比、主实验与附录分析、观察结果与作者解释、计划与已验证结论。
6. 按[视觉与渲染指南](references/visuals.md)为每段选择画面。先用核实过的原图和数据，需要解释空间、机制或反馈时再补示意图。选用当前平台具备的渲染方式，图表数据和编辑规则可脱离绘图库复用。
7. 按 [交付检查](references/harness-and-review.md#交付检查) 审读实际渲染。追溯每个关键数字和有疑义的术语。核对引文、裁切、对齐和图面信息的重复。宿主无法导出 PNG 时，在交付清单写明缺项，提供可打开的图源和证据表。修订时用反馈记录连接用户意见、改动位置、验证证据和剩余问题。
