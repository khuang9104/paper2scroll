# 中文编辑规范

- 默认用简体中文。用户指定繁体、地区用语或术语表时从其要求。论文、数据集、模型和软件的正式名称沿用原文拼写，首次出现时用一句中文说明它是什么。
- 术语以论文定义和使用场景为准。需要译成中文时，优先采用语义一致的通行专业译法。遇到多义词或不确定的译名，先查论文方法、图注或作者引用的原始资料，再查标准或权威领域文献。仍无把握时保留原文术语，配一句描述其作用的话。不要猜测含义、创造译名或把解释写成作者术语。
- 首次使用确有必要的简称时，写清「中文术语（原文简称）」及其含义。只出现一次的术语、已有清楚全称的项目名，直接用全称。核对作者或领域实际用法，尤其注意大小写。普通中文缩略语也按同一原则处理。
- 用具体的对象、动作和条件表达结论。标题写「只给彩色图像，成功率和模型调用次数怎么变？」，正文交代模型与数值。「调用次数」和「费用」分别对应不同指标。
- 并列条件和失败类型可用短项目符号。前因后果用短段落或编号步骤。图注明确对象和原图号，技术词解释放在相关画面旁。术语一旦译定，在图题、图例和正文沿用同一写法。
- 保留数值的单位、分母和限定词。两组成功率由 80% 到 85% 写「增加 5 个百分点」。相对变化只有在论文使用或能据原数据准确计算且有必要时另行说明。
