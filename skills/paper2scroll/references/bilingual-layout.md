# 中英对照排版

选用 `zh-en` 时，独立图、综合图、证据表和交付清单的自编文字全部中英对照。标题、小标题、段落、流程节点、图注、表头、轴标签、图例和来源说明都按阅读单元先中文后英文。一个完整意思的中文下面紧跟对应英文，再开始下一组。论文题名保留原题，无通行译名时提供忠实译文。作者原名、正式专名、图号和共用数字可只写一次。原图保留原有文字，理解原图所需的标签在旁边用双语说明。

- 同一组中英文共用左边线、栏宽和视觉标记。中文作为主行，英文略小或略浅，保持实际阅读尺寸的可辨认度。组内间距小于组间间距。
- 标题、图例或表格较长时，优先增加高度或列宽。表格在同一单元格内上下排中英文字，数值放同一列共享。图表和图片共享，图注紧随图片。
- 先定每组表达的事实和边界，再写两种语言。对照检查数字、限定条件、语义、术语和出处，两行指向同一份证据。排版时重点检查英文长词、中文行末和图例对齐。
