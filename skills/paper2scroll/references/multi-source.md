# 多资料综合

## 阅读目标与来源

分别确定读者的两个目标。第一，逐份读懂作者或资料编写者想回答什么。第二，理解为什么要把这些资料一起看，放在一起能解释什么。优先采用用户明说的目的。目的未说明时，从任务和材料推定一个可修正的阅读问题，避免把编辑者的推断写成作者意图。

登记每个输入 PDF 和其他独立来源的标题、版本、日期类型和可读范围。给每份文件一个短标识，贯穿独立图、综合图和论点证据表。转写、附录与原文之间记录从属关系，同一原文的多个版本在综合中注明证据关系。

## 第一层 · 每份资料独立成图

每个 PDF 都对应一个可单独打开的长图文件。对完整论文应用单篇流程。对附录、节选和其他资料按实际内容与体裁组织，说明其问题、依据和适用范围。

- **意图**交代作者明确想回答什么，以及读者看这份资料想解决什么。两者可能不同。
- **故事线**决定从哪里进入、为什么接着看下一节。按材料选具体案例、矛盾或关键发现，再进入机制、证据和结论。
- **描述**解释每个画面或关键证据表示什么、在什么条件下成立、和主问题有什么关系。案例、方法、测量结果和作者解释各自标明。

覆盖每份资料的核心贡献和关键限制。综合图中的一句摘要不能代替独立长图。

## 第二层 · 跨资料综合

按材料中的共同背景、关键关系和结论边界组织阅读顺序。定完分组后，再用读者容易理解的问题或发现写标题。配图旁说明图中的关系、成立条件及其意义。

**按证据分组数决定张数。** 从原文提取可定位的跨资料关系，例如同一结论的支持或分歧、方法演变、不同条件下的结果。每组至少涉及两份资料，形成一项独立的综合发现。指向同一发现的关系合在一组。方法、尺度或适用条件差异会改变结论，且需要分别展示证据时，再拆组。重复版本、页数和引用次数不增加组数。

成图前在论点证据表简记分组、关键来源和预计张数。只有一组就做一张，两至四组按组各做一张，五组或更多做五张。超过五组时将最相近的组并入同一图的不同章节，并保留条件区别。找不到可证实的关系时，用一张图说明材料覆盖与证据缺口。交付前核对实际张数，用来源标识连接各份独立图。

| 读者想知道 | 怎么呈现 | 证据要求 |
|---|---|---|
| 谁先做，后来哪篇回应了它 | 时间线或引用关系图 | 注明日期类型。时间箭头只表示先后。引用方向从引用者指向被引用者，并标出处。改进、继承或因果需要额外证据。 |
| 方法、实验和结论哪里一致或不同 | 同问题的对照图或证据矩阵 | 每项回到原文位置。实验任务、样本、指标和预算对齐后才比较数值。 |
| 两份证据能否互补，或为什么看起来矛盾 | 机制图、适用条件图或分歧对照 | 说明各自证明了哪一步。先核对定义、数据与条件，再判断是否有实际冲突；解释不了就保留分歧。 |
| 这批资料把领域的哪些问题讲清了，还有什么没讲到 | 领域问题图或证据分布图 | 标出材料覆盖的范围。未被本批材料覆盖不等于领域尚无研究；使用补充资料时单独标明来源。 |
| 放在一起有什么新解释或启发 | 机制对读、条件图或待验证问题图 | 分开写跨资料综合、设计启发与待验证问题。每条综合都能回到所用资料。 |

**启发要具体。** 每章用来自至少两份资料的可定位观察，说明放在一起看多知道了什么：例如一个方法为何适用于某个条件、一个看似矛盾的结果应如何解释，或下一步该优先验证哪个变量。提出比较或实验时，写明要固定的关键条件和用什么结果判断。标明哪些是原文结论、哪些是基于多份资料的编辑推论或待验证问题。证据不足时，说明哪些关系目前无法判断、还缺哪类证据。

为每章在[论点证据表](evidence-map.md)另记一行章级摘要：`读者问题｜关系与来源定位｜多知道了什么｜结论边界或待验证项｜对应图章`。一章含多条关键关系时，逐条记录关系类型和出处。登记的独立来源都应有长图入口；证据相关性决定它是否出现在某个综合章。无法建立实质联系时，在综合中注明原因或证据缺口。

例子。两篇机器人论文可以先各自讲清研究目的、控制方法和实验，再用一张关系图呈现引用、程序层与模型层反馈的区别，以及统一实验条件后才能检验的问题。实验覆盖可写成「实验覆盖与方法局限（Evaluation scope and limitations）」。耗时可独立写成「实机任务耗时（Hardware task completion time）」。只有数据支持明确的得失关系时才称为 trade-offs。
