# 视觉与渲染指南

先确认这一段需要读者看清什么，再选画法。

| 读者要看清什么 | 可用画法 |
|---|---|
| 设备、现场或动作顺序 | 带原图号的实拍分镜，或有明确标签的空间示意 |
| 机制、因果顺序或反馈 | 带方向的流程、俯视图、剖面或前后状态 |
| 同一对象在两种条件下的差异 | 共用尺度的配对点图，按对象排列，两端直接标注 |
| 多个模型和条件 | 同尺度小图并排，或对齐的表格。只在可比较时共用尺度 |
| 结果分布和不确定性 | 论文支持时用分布图或区间，交代区间含义和样本量 |

章节可用不同构图。每篇按主题、原图和数据另选配色，记录主色和强调色各自表达什么。单张图内让同一种条件保持同一种标记。章节主题色可变化，数据用色以可比较为先。用标签、线型或形状补充颜色，在正常阅读尺寸检查文字对比。注释放在对应的数据和动作旁。

先对齐封面标题、标签和副标题的左边线，再检查正文的栏宽、图注起点、数字列和章节间距。删去冗余过渡后重新收紧空白。圆点或分隔符只在表示列表、图例或明确的分组关系时使用。

把三项导读放在一个紧凑、可扫读的独立区域。用统一底色、侧栏或标题层级标出它的边界。正文用另一种层级展开，例如用章节标题、图表、时间线或证据对照。导读里若有理论关系或论证步骤更适合用图解释，可加小示意，用所选语言标注，并标明是编辑示意及其出处。检查看成品时能否直接认出导读结束和正文开始的位置。

原图、按论文数据重绘的图、解释性示意分别标明。可手绘或用当前平台的图像工具补插图，再核对关键物体、顺序和方向。用可复核的数据渲染轴、图例和数值。静态图片旁保留论文图号、表号或章节。可点击版本和交付消息提供具体出处，核对链接确实落到所标注的位置。若要单文件分享，把长图用到的图片嵌入图源；原论文通过出处链接查阅。需要离线归档时另行附原文。

## 可选工具

- [AntV Infographic](https://github.com/antvis/Infographic) 适合分镜、时间线和快速排版。选模板后仍要验证阅读顺序、反馈箭头、字体和裁切。
- [Observable Plot](https://observablehq.github.io/plot/features/facets) 适合配对点图、同尺度小图和带区间的比较。用同一份证据数据驱动画面。有本地 JavaScript 环境时可用，其他环境可以用已有绘图库或原生矢量图复现。
- [科学示意图的草图和审阅流程](https://github.com/K-Dense-AI/scientific-agent-skills/blob/main/docs/skill-guides/scientific-schematics.md) 可借来处理原理示意。按当前平台的可用能力绘制。

核心按 [Agent Skills 规范](https://agentskills.io/specification) 组织，使用相对路径引用。绘图库和图像工具为可选能力。优先用平台已提供的工具和依赖，备选是原生矢量图或可交接的绘图稿。内容与数据应能独立于渲染器审查。
